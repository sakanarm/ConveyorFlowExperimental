# ConveyorFlow Submission Readiness Checklist

## Complete

- Main simulation: 22,500 unique runs with 50 paired seeds
- Public-data-derived ML Build and Fix Bug workloads
- Frozen design, configuration, source snapshot, event ledgers, and SHA-256 manifests
- RQ1-RQ3 and no-volunteer fallback analysis with resource-regime stratification
- Paired seed-cluster bootstrap intervals, Wilcoxon signed-rank tests, and Holm correction
- Radar visualization with an explicit non-inferential interpretation boundary
- Secondary Pareto frontiers and run-level competing-risk cumulative incidence
- IEEE-style English manuscript and Thai advisor explanation
- Real-LLM pilot protocol, case-selection script, configuration template, and adapter contract

## Must be completed by the researcher or advisor

- Human-expert validation of task-difficulty labels
- Advisor approval of the scientific claim and target-journal fit
- Author list, affiliations, corresponding author, ORCID, funding, acknowledgments, conflicts, and ethics statements
- Repository/archival DOI and an anonymized review package if the journal uses double-blind review
- Target-journal template, word/page limits, reference style, graphical requirements, and required declarations

## Optional but strongly recommended before submission

- Execute the frozen Real-LLM pilot after exact model snapshots, API prices, task bundles, and validators are available
- Freeze a Main Real-LLM sample size from pilot precision before observing comparative results
- Add a short threat-to-validity paragraph distinguishing mechanism validity, label validity, and model/vendor external validity
- Archive software environment information and a one-command reproduction script

## Claim gate

The current paper may claim simulation-conditional effects of decentralized self-selection,
capability heterogeneity, fit, stand-down, aging, and fallback behavior. It must not claim
human-validated difficulty ground truth or measured performance of named production LLMs until
those studies are completed.
